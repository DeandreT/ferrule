# #443 proposed runtime conservation policy

This source-bound proposal precedes owned Starting implementation. It is not
approval of an uninspected runtime delta or of generated execution.

## Fixed comparison inputs

Use the historical ordinary artifact manifest and complete Cargo template in
`legacy-baseline/`. Historical generation is from exact merged f30f6ca1 source,
ordinary lower/Rust emit/C# emit, with package `ferrule-generated-mapping` and the
recorded explicit runtime operand. Full original artifacts and generation
receipts remain separately preserved in `../starting443-historical-artifacts-v1/`.
Its `inputs/` copies match the independently sealed literal baseline; the larger
corpus's old_profiles.rs custody failure is not inherited as baseline authority.

## Independently named policy

The shared harness may add a separately named `ReviewedStartingRuntime` policy
and Starting-specific snapshot entrypoint. Existing `ExactHistorical`,
`ReviewedAdjacentRuntime`, their callers and historical manifests keep their
current semantics. Sharing internal exact-path comparison mechanics is allowed;
selecting the Adjacent policy is not an authorization substitute.

Starting's exact artifact/source pairs are:

1. Runtime/FerruleBasicGroupBy.cs -> runtime/csharp/Ferrule.Runtime/FerruleBasicGroupBy.cs
2. Runtime/FerruleInstance.cs -> runtime/csharp/Ferrule.Runtime/FerruleInstance.cs
3. Runtime/ScopeContext.cs -> runtime/csharp/Ferrule.Runtime/ScopeContext.cs

The complete ordered unique 78-path inventory must match. For the other 75
files, all bytes remain historical. For these three paths, the independently
reviewed pre-emission candidate source bodies are the only alternative expected
bytes; hashes of emitted outputs cannot define the expectation.

## Allowed source scope, still requiring actual delta review

- Add the narrow Boolean Starting controls interface and operation inside the
  existing grouping source; preserve By/Adjacent interfaces and their callbacks.
- Generalize private KeyedGroup markers to GroupMembers through every
  mint/copy/use path in the three named files, preserving ordinary Item shadowing
  and exact owner/root authorization.
- Dispatch only the explicitly admitted By, Adjacent and Starting operations.
  Evaluate Starting boundaries before post retention, retain the initial false
  prefix, and retain/drop complete groups according to the accepted contract.
- Preserve all retained fields, arrays, templates, one-shot capabilities, checked
  resource equations and failure frontiers. A Boolean boundary adds no grouping
  key text, no retained adapter, no new per-group object and no additional backing.

Before emission, retain merged-base and candidate full bodies, old/new
path-size-hash rows and complete source diffs. The actual implementation's
independent review must cover every allowed delta; this scope description alone
cannot make a changed candidate acceptable. Bind the reviewed source into the
generator build, verify all three emitted bodies equal it, and verify source
unchanged after emission. Any fourth path or retained-layout change refuses.

## Enforcement and coverage

Require explicit Starting policy selection, exact sorted unique paths, exact
stable rows, exact source rows and unchanged source. Report historical equality
separately from policy acceptance. Reject unknown/missing/duplicate snapshot
paths and unreviewed bodies, extra/missing artifacts, changed generated files,
changed stable runtime files and mutation after snapshot. Existing Adjacent
controls must continue to pass without changing their expected values.

Rust ordinary library bytes remain exact; only the single explicit Cargo
runtime-path operand may vary through the proven template. Compare old By to
By, ItemAt to ItemAt, and Adjacent to Adjacent under unchanged options in separate
controls. No new Starting output is a historical oracle.

The historical source archive and literal baseline must still bind the pristine
implementation checkout before exclusive write grants. Actual runtime-delta
review follows implementation and precedes candidate emission/consumer builds.
