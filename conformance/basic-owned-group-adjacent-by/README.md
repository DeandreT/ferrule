# Basic owned adjacent grouping: literal public-Project corpus

This finite corpus exercises the explicit
`*_with_basic_owned_group_adjacent_by` generation companion and the unchanged
Basic owned execution APIs. Its oracle is authored in `cases.rs`, not copied
from native or generated results. `projects.rs` constructs genuine public
Projects; `closed.rs` and `closed_specialized.rs` keep negative Projects and
deliberately malformed direct Programs separate from mapping execution.

## Preparation and qualification protocol

The CLI module is `basic_owned_group_adjacent_by.rs`, registered in
`code_generation.rs`. Nonignored harness tests check exact inventory/codec
recipes, raw-capture continuation/original-file fences, complete typed closed
Project/direct-Program diagnostics, and the immutable historical manifest,
complete Cargo template and four archival runtime bodies.

1. Freeze the authored source proposal externally, then build the current test
   binary only with the coordinator's compiler-lane grant.
   `RUSTC`, `RUSTC_WRAPPER` and `RUSTC_WORKSPACE_WRAPPER` must be unset; this
   campaign binds the default compiler route rather than override executables.
2. Set `FERRULE_BASIC_ADJACENT442_PREPARE_DIR` to an **absent absolute path**
   with an existing parent. Run ignored
   `basic_adjacent442_prepare_public_projects_and_callers`. This operation
   does not compile a generated host or run a mapping/native evaluator. It
   writes all literal controls/Projects/catalogues/refusals, original emitted
   files, callers and their bindings before allowing qualification.
3. Preserve that complete materialized v1 proposal and its hashes externally.
   Review preparation mismatches; never substitute an actual output for an
   authored expectation. A success marker binds every original evidence file,
   the complete implementation/borrowed-helper source closure, test binary,
   command executables, runtime path and environment preflight receipts.
4. With a separate serialized compiler/native-lane grant, run ignored
   `basic_adjacent442_qualify_native_and_public_consumers` against the same
   unchanged preparation and test binary. It refuses stale originals before
   executing. Host commands use the existing `host_policy` recorder and its
   environment/source fences, isolated .NET home and global-tool PATH opt-out.
5. Retain raw original products, error cause chains, lossless Float/XML-origin
   captures and comparison failures. A mismatch or observer failure does not
   skip later calls/models/engines. Required evidence I/O failure is fatal.
   No automatic expectation update exists.

The qualified #473 `codec.rs`, native driver, host templates and ordinary
legacy hosts are reused through explicit cross-file paths. All CLI tests and
templates are in the source binding, alongside the implementation closure
(at least the original 855 source bindings) and every tracked historical
baseline/provenance file. External qualification contracts and source archives
are not prerequisites for running this corpus. No new lossy owned-tree parser
is introduced.

separate control, never substituted for same-profile historical conservation.

conservation inputs; their tests/evidence are not regenerated by this module.
