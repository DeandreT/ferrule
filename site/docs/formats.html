Supported formats

Format adapters translate external documents into `ir::Instance` and write target instances back out. Extension dispatch covers common cases; embedded format options carry dialects, layouts, and schemas.

The tables below are generated from the format reference. Each claim belongs to one category:

  • Implemented capability: behavior of the native format adapters and the CLI that uses them, backed by the source and tests cited in the canonical reference.
  • Qualified route: a separately named route, such as a generated library adapter or an editor workflow, with its own contract or qualification record. It covers only that route and profile.
  • Unsupported profile: a named shape, direction, or behavior outside the implemented scope. The runtime refuses it or, where stated, deliberately does not apply it. The list is not exhaustive.

These references describe finite, tested coverage. They are not a parity claim for a complete format standard or another product.
