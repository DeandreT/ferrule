Chapter 4

Supported formats

Format adapters translate external documents into `ir::Instance` and write target instances back out. Extension dispatch covers common cases; embedded format options carry dialects, layouts, and schemas.

Boundaries

  • PDF output is intentionally unsupported.
  • XBRL taxonomy formula, presentation, calculation, and linkbase execution are not interpreted.
  • XML preserves declared expanded names, and MFD export writes foreign declarations as an atomic local XSD graph. Mapping paths use local field names, so XSD import explicitly rejects siblings that differ only by namespace. Optional/unbounded named model groups with exactly one nonrepeating member flatten to that member's repeated field. Exact optional/unbounded ##local element wildcards declared inline or through named model groups, and direct or named-attribute-group ##local attribute wildcards with processContents="skip", are supported; other namespace-aware or validating wildcard shapes remain outside the subset.
  • JSON Schema flattens compatible allOf branches and preserves heterogeneous scalar type arrays, exact scalar anyOf, pairwise-disjoint scalar oneOf, identical or scalar-domain-subsumed array anyOf branches, selected object alternatives, nullable scalar/object/array wrappers, and typed or unconstrained dynamic properties. Bounded scalar const/enum sets, exact integer or finite-number ranges, positive finite decimal multipleOf constraints, exact minItems/maxItems array intervals, exact minLength/maxLength string intervals, and portable pattern assertions are enforced on input and normalized output. Allowed-value sets may combine strings, booleans, signed integers, exactly representable finite numbers, and JSON null; references and compatible allOf intersect them, finite scalar anyOf unites them, and finite scalar oneOf retains values admitted by exactly one branch. Structured enum members remain unsupported. multipleOf uses exact canonical decimal arithmetic without epsilon comparison; compatible allOf conjunctions and exact anyOf disjunctions survive. Contiguous same-type numeric range branches normalize to one exact interval when their divisor constraints are identical, while unions that correlate different numeric ranges with different divisors reject rather than widen. String assertions remain conditional on string runtime values in scalar unions; null bypasses them. They survive references according to each resource's dialect, compatible allOf conjunction, exact anyOf disjunction, disjoint scalar oneOf, array items, typed dynamic properties, and canonical export. Ferrule's Unicode-scalar pattern language supports anchors, dot, classes and ranges, alternation, groups, standard and counted repetition, lazy suffixes, and explicit character/Unicode escapes. Backreferences, lookaround, named groups, inline flags, Unicode properties, shorthand classes, octal/control escapes, and class-set operators reject rather than vary by backend. Programs, schema metadata, and each JSON document parse or serialization call's matching work are bounded; native and generated Rust/C# use the same matcher. JSON Lines validates root item counts and each string item across all nonblank lines. Unknown and empty string format annotations are retained exactly on string-capable values and array items, including through compatible compositions and references, but named format vocabularies are not asserted at runtime. Annotations on non-string values and arbitrary-JSON nodes are syntactically validated but not retained. Annotation metadata is bounded to 64 distinct values, 1 KiB each and 16 KiB total per node. $ref siblings follow the dialect declared by each physical schema resource: Draft 4, 6, and 7 ignore them, while Draft 2019-09, 2020-12, and schemas without $schema apply Ferrule's supported sibling metadata and assertions. Unsupported modern structural intersections reject explicitly, and external resources select their own policy. Heterogeneous or correlated numeric-range scalar unions, disjoint count or string-length unions, independently constrained nested array wrappers, general heterogeneous array composition, mixed structural unions, and other validation keywords remain outside the runtime.
  • Database execution is SQLite-specific today.
  • EDI output validation runs after wire lexical formatting and leaves the destination unchanged on failure.
